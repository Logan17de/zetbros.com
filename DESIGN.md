# Zetbros design preferences

The Zetbros brand theme is building from zero, expressed as “From zero to something real” directly beneath the homepage logo. Treat it as a quiet, centered tagline with no terminal punctuation, content box, border, or background. Show the path from a first idea or real problem to something useful for people, society, or businesses. Keep the claim grounded in actual work; do not imply that every business engagement discards the systems a company already uses.

Preserve the original Zetbros logo, favicon assets, content, routes, and tagline placement. The authorized frontend refresh uses the open editorial studio direction documented in `docs/frontend/design-brief.md`. The homepage's SVG icon artwork is the reference for the icon style.

Use a readable, humanist sans-serif family. The current Segoe UI family is the shared reference. Do not introduce monospace, robotic display type, or emoji artwork into product pages.

Use unboxed headings on every page, including Harness, research, business examples, and legal pages. Heading wrappers have no padding, border, background, rounded corners, or shadow. Preserve the shared word-reveal motion and use typography and spacing for hierarchy.

Harness should read as a compact visual guide: short explanations, small line icons, useful connection diagrams, and restrained heading sizes. Prefer space and alignment to large decorative feature cards. Keep production status and the fact that proposed connectors are examples clear. Preserve the distinction between declared plugin access and actual security isolation.

Use a white canvas, graphite reading text, deep teal actions drawn from the logo, thin structural rules, and unboxed narrative content. Use `app/studio.css` semantic tokens across CSS Modules. Keep diagram boundaries only where they communicate a real group; shadows belong to the contact overlay. Retain the existing CSS and native dialog instead of adding a component library.

Harness infographic groups and homepage sections use short settling motion with a reduced-motion fallback. All text must remain visible before JavaScript or animation; no long stagger chains, blur reveals, decorative glow, or perpetual movement.
